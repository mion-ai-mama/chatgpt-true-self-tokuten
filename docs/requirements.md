## 0. アーキ構成

- 確定アーキ: #6 WEBアプリ（決定論）
- 操作者: ブラウザのエンドユーザー（Instagramリール視聴者）
- AI本体(プロンプトY): なし（ページはすべて静的。ChatGPTへの質問文はコピペ用の固定テキストとして埋め込む）
- MCP: なし
- 自社DB: なし
- フロントUI: あり（このリポジトリそのものがフロントエンド全体）
- 動的変数: なし
- 種別: Web型（静的サイト。バックエンド・DB・ビルド工程なし）
- 配布: マイ専用（発信用GitHubアカウント mion-ai-mama 配下の個人リポジトリ）
- ホスティング: GitHub Pages（無料・静的ファイル配信のみ）
- 出自: `mion-ai-mama/instagram-tokuten-template` を「Use this template」で複製して作成。
  元テンプレートの `content.js` 単一ソース＋汎用コピー機構は踏襲しつつ、本ページ固有の
  セクション（準備・自己紹介テンプレート・5つの質問カード・行動プラン・まとめ）を追加した。

## 1. プロジェクト概要

- 成果目標: Instagramリールのコメント特典として、リール内で紹介した「ChatGPTで本当の自分を
  深掘りする5つの質問」を、コピペしてすぐ使える形の1ページ完結型ガイドとして配布する。
- 想定読者: 40〜50代の女性・ママ、ChatGPT初心者、今の自分や働き方にモヤモヤしている人。

### 成功指標（定量）

- 特典ページ → CTA（AIマネタイズの教科書）のクリック率
- リールのプロフィールリンク経由の特典ページ到達率
- ページ最後（まとめ・CTA）までの到達率
- 各コピーボタンの利用率（個別コピー／まとめてコピー）

### 成功指標（定性）

- ChatGPT初心者でも迷わず、質問をコピペして送るだけで完結する体験
- 「自分でも気づいていない部分」への気づきを、怖さを感じさせずに提供できること
- スマホでサクサク読める、情報過多に感じさせない余白・構成

## 2. システム全体像

単一のランディングページ（`index.html`）に、以下の11セクション＋標準CTAを縦に並べる構成。
ロール・認証はなし（誰でも閲覧可能な公開ページ）。

1. OP画像（`heroImage`。2026-09-03追記: OGP画像として用意した画像をページ本体にも
   表示するよう追加。タイトル・サブコピーは画像内にあるため、直下でテキストとして
   繰り返さない）
2. ファーストビュー（`hero`・画像に含まれない補足文とCTAボタンのみ）
3. この資料でできること（`tips`・カード3つ）
4. 始める前の準備（`prep`）
5. 自己紹介テンプレート（`introTemplate`・コピー機能）
6. 5つの質問（`mainQuestions`・個別コピー＋まとめてコピー）
7. 回答が浅かったときの深掘り質問（`extraQuestions`・個別コピー）
8. 30日間の行動プランプロンプト（`actionPlan`・コピー機能）
9. 大切な注意点（`caution`）
10. まとめ（`summary`）
11. CTA（`cta`・全ページ共通の「AIマネタイズの教科書」導線、常時表示）

## 3. データ設計概要

DBなし。すべて `js/content.js` の `CONTENT` オブジェクトが単一の真実の源。
ユーザーの入力内容はページ内に保存せず、外部へも送信しない（コピー機能のみ・通信なし）。

## 4. セキュリティ要件

- ログイン・認証不要の公開静的ページ
- APIキー・Cookie・外部送信処理なし
- `noindex, nofollow`（検索結果への積極的な表示は不要な特典ページのため）

## 5. 技術スタック

- HTML5 / CSS3 / Vanilla JavaScript（フレームワーク・ビルド工程なし）
- ホスティング: GitHub Pages（Vercelでの公開にも対応、README §5参照）
